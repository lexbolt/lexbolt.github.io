WinSwitch

Автоисправление раскладки для Windows — перепечатывает слова, набранные не в той раскладке.

Бета 2026

Набрали ghbdtn вместо «привет»? WinSwitch замечает, что слово набрано не в той раскладке, стирает его, перепечатывает правильно и переключает раскладку — как когда-то Punto Switcher.

  • Живёт в трее: пауза, включение автоисправления, настройки, пошаговый гайд.
  • Низкоуровневые хуки клавиатуры и мыши, SendInput, работа с раскладками через Win32 API.
  • Поставляется папкой, а не одним exe, чтобы антивирусы не принимали его за угрозу.

Стек

  • Python
  • Win32 API
  • ctypes
  • tkinter
  • PyInstaller
