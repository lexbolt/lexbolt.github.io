Фирменный стиль LEXBOLT

Фирменный стиль с нуля — знак «болт-L», палитра, шрифты, тема Material 3 и файлы для типографии.

Работает 2026

Стиль этого сайта. Знак — перевёрнутый шестигранный болт: золотой стержень и две грани головки образуют букву L, тёмная левая грань сохраняет силуэт болта.

  • Один скрипт на Python собирает всё: логотипы, фавиконки, обложки соцсетей, визитки, стикеры, макеты сувениров.
  • Текст в кривых, файлы для печати с вылетами, CMYK и Pantone.
  • Тема Material 3, рассчитанная из фирменного золота, — основа этого сайта.

Стек
