WinSwitch

Automatic keyboard layout fixer for Windows — retypes words typed in the wrong layout.

Beta 2026

Esta página aún no está traducida a tu idioma, por eso se muestra en inglés.

Typed ghbdtn instead of привет? WinSwitch notices the word was typed in the wrong layout, erases it, retypes it correctly and switches the layout — the way Punto Switcher used to.

  • Lives in the system tray: pause, auto-correction toggle, settings, step-by-step guide.
  • Low-level keyboard and mouse hooks, SendInput, layout handling through Win32 API.
  • Ships as a folder build rather than a single exe, so antivirus tools do not flag it.

Tecnologías

  • Python
  • Win32 API
  • ctypes
  • tkinter
  • PyInstaller
